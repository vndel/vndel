### About

I build the parts users never see — the API that stays up, the schema that scales,
and the auth layer that does not leak. Most of my work lives in production behind
game servers, Discord bots, and licensing systems.

- Founder of **[FiveM Code Hub](https://team.fivemcodehub.com)** — a small team shipping production backends

- I care about documented endpoints, real error handling, and monitoring from day one
